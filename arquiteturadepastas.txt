Fluxo do Grafo antes do código

Mensagem WhatsApp
       │
       ▼
┌─────────────┐     bloqueada      ┌──────────────┐
│  Guardrails │ ─────────────────► │  Resposta    │
│  (entrada)  │                    │  de bloqueio │
└─────────────┘                    └──────────────┘
       │ ok
       ▼
┌─────────────┐
│Recepcionista│  ── identifica cliente, boas-vindas, detecta intenção
└─────────────┘
       │
       ├── intenção: INFORMACAO  ──► AgentInformacoes
       ├── intenção: AGENDAR     ──► AgentAgendamento
       ├── intenção: REMARCAR    ──► AgentAgendamento
       ├── intenção: CANCELAR    ──► AgentAgendamento
       └── intenção: SAUDACAO    ──► Recepcionista responde direto
                                          │
                                          ▼
                                  ┌─────────────┐     bloqueada
                                  │  Guardrails │ ──► resposta padrão
                                  │   (saída)   │
                                  └─────────────┘
                                          │ ok
                                          ▼
                                   Envia ao cliente
